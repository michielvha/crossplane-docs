# Crossplane Docs promotional draft

When working with crossplane at customers a barrier to entry I often notice with teams that are new to kubernetes is all the YAML, developers are used by now to read api references but a big xrd or composition still feels daunting,

when working with terraform as a platform engineer I often used terraform docs to bring some clarity to our terraform repos,

for crossplane such a tool does not yet exist so I put my agents to work and created one, couple iterations later and I want to present this tools to others because I believe it has gotten quite good…

Read more: https://vhco.pro/projects/crossplane-docs/intro.html
